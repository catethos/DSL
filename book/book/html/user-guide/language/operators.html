DSL Documentation

Operators

DSL provides a rich set of operators for arithmetic, comparison, logical operations, composition, and data flow.

Arithmetic Operators

Basic mathematical operations on numbers.

+
-
*
/
^

Examples

10 + 5
20 - 3
4 * 5
100 / 4
2 ^ 8

With Variables

let x = 5
x + 10
x * 2
x ^ 2

Type Mixing

Int and Float can be mixed - Int is automatically promoted to Float:

5 + 3.14
10 * 2.5

Tip

Automatic type promotion means you don’t need to manually cast integers to floats.

Comparison Operators

Compare values and return boolean results.

==
!=
<
>
<=
>=

Examples

5 == 5
5 != 3
3 < 5
10 > 5
5 <= 5
10 >= 5

With Variables

let age = 18
age >= 18
age < 21

String Comparison

"hello" == "hello"
"a" != "b"
"apple" < "banana"

Logical Operators

Combine and manipulate boolean values.

&&
||
!

Examples

true && true
true && false
true || false
false || false
!true
!false

Complex Conditions

def main() {
    let age = 18
    let verified = true

    age >= 18 && verified
    age < 13 || age > 65
    !(age < 18)
}
main()

Short-Circuit Evaluation

Note

&& and || use short-circuit evaluation: the second operand is only evaluated if needed.

false && expensive_function()
true || expensive_function()

Pipeline Operator |>

The pipeline operator chains operations left-to-right, passing results forward.

Syntax

expr1 |> expr2 |> expr3

The result of each expression automatically becomes available to the next.

Basic Pipelines

"hello" |> Upper

"hello" |> Upper |> Length

[1, 2, 3, 4, 5] |> Length

Multi-Step Pipelines

"hello world"
|> Upper
|> Split(" ")
|> Join("-")

Pipeline with Functions

[1, 2, 3, 4, 5]
|> map(_, fn n => n * 2 end)
|> filter(_, fn n => n > 5 end)
|> Sum(_)

Pipeline with Binding

["a", "b", "c"]
|> Join("-") as joined
|> Upper

Why Use Pipelines?

Pipelines make data transformations readable by showing the flow of data left-to-right, just like reading text.

Conditional Operator ?:

Branch based on a condition (ternary operator).

Syntax

condition ? true_expr : false_expr

Examples

def main() {
    18 >= 18 ? "adult" : "minor"

    let age = 25
    age >= 18 ? "adult" : "minor"

    let active = true
    let verified = true
    active && verified ? "proceed" : "reject"
}
main()

In Pipelines

let age = 30
age |> (age >= 18 ? "adult" : "minor")

Nested Conditionals

let score = 85
score >= 90 ? "A" : (score >= 80 ? "B" : (score >= 70 ? "C" : "F"))

Tip

For multiple conditions, consider using pattern matching (experimental feature) for better readability.

Parallel Execution par()

Execute expressions concurrently and collect results.

Syntax

par(expr1, expr2, expr3)

Results are collected into a list.

Basic Parallel

par(5, 10, 15)

par(5, 10, 15) as numbers

Parallel Destructuring

par(10, 20, 30) as [a, b, c]

a + b + c

Parallel Function Calls

par(
    Sum([1, 2, 3]),
    Sum([4, 5, 6]),
    Sum([7, 8, 9])
) as results

Sum(results)

Use Cases

  • Parallel API calls
  • Concurrent LLM queries
  • Batch data fetching
  • Independent computations

Performance

Use par() when operations are independent and I/O-bound for significant performance improvements.

Field Access Operator .

Access fields in maps and custom types.

Syntax

object.field
object.nested.field

Examples

def main() {
    let user = { "name": "Alice", "age": 30 }
    user.name
    user.age

    let data = { "address": { "city": "Boston" } }
    data.address.city
}
main()

With Custom Types

class Person {
    name: String
    age: Int
}

let alice = Person { name: "Alice", age: 30 }
alice.name
alice.age

Index Access Operator []

Access list elements by index (0-based).

Syntax

list[index]

Examples

let numbers = [10, 20, 30, 40, 50]
numbers[0]
numbers[2]
numbers[4]

Dynamic Indexing

let i = 2
numbers[i]

Operator Precedence

From highest to lowest priority:

  1. Parentheses - ()
  2. Field/Index Access - ., []
  3. Function Calls - func(args)
  4. Exponentiation - ^
  5. Multiplication/Division - *, /
  6. Addition/Subtraction - +, -
  7. Comparison - ==, !=, <, >, <=, >=
  8. Logical NOT - !
  9. Logical AND - &&
  10. Logical OR - ||
  11. Conditional - ?:
  12. Parallel - par()
  13. Pipeline - |>
  14. Binding - as, let

Precedence Examples

10 + 5 * 2
(10 + 5) * 2

2 ^ 3 * 4
2 ^ (3 * 4)

5 > 3 && 10 < 20

(5 > 3) && (10 < 20)

Tip

When in doubt, use parentheses to make your intent explicit.

Operator Combinations

Arithmetic + Comparison

def main() {
    let x = 10
    let y = 20
    (x + y) > 25
}
main()

Pipeline + Conditional

[1, 2, 3, 4, 5]
|> Length
|> (_ > 3 ? "many" : "few")

Parallel + Pipeline

par(

    [4, 5, 6] |> Sum,

Common Operator Patterns

Pattern 1: Data Transformation Pipeline

"hello world"
|> Upper(_)
|> Split(_, " ")
|> map(_, fn w => w + "!" end)
|> Join(_, " ")

Pattern 2: Conditional Processing

def main() {
    let score = 85
    let grade = score >= 90 ? "A" :
                score >= 80 ? "B" :
                score >= 70 ? "C" :
                "F"
}
main()

Pattern 3: Parallel + Aggregate

par(
    fetchUserData(1),
    fetchUserData(2),
    fetchUserData(3)
) as users
|> map(_, fn u => u.age end)
|> Avg(_)

Pattern 4: Complex Logic

def main() {
    let age = 25
    let verified = true
    let premium = false

    let access = (age >= 18 && verified) || premium ?
        "granted" : "denied"
}
main()
