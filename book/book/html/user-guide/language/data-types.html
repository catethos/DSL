DSL Documentation

Data Types

DSL provides a rich type system with primitive types, composite types, and special types for different use cases.

Primitive Types

String

Text data enclosed in quotes.

"hello world"
'single quotes also work'

String Operations:

Upper("hello")
Lower("WORLD")
Length("hello")
Split("a-b-c", "-")
Join(["a", "b"], "-")
Replace("hello world", "world", "DSL")

Template Strings:

let name = "Alice"
"Hello, ${name}!"

Int

Integer numbers (whole numbers).

42
-10
0
1000

Int Operations:

10 + 5
20 - 3
4 * 5
100 / 4
2 ^ 8

Math Functions:

Abs(-42)
Min(5, 10)
Max(5, 10)

Float

Floating-point numbers (decimals).

3.14
-0.5
2.71828
0.0

Float Operations:

3.14 * 2
10.5 + 2.3
5.0 / 2.0

Math Functions:

Round(3.7)
Floor(3.7)
Ceil(3.2)
Sqrt(16)

Auto-Promotion:

When mixing Int and Float, Int is automatically promoted to Float:

5 + 3.14
10 * 2.5

Tip

The DSL automatically promotes integers to floats when needed, so you don’t need to manually cast.

Bool

Boolean values representing true or false.

true
false

Boolean Operations:

true && true
true || false
!true

From Comparisons:

5 > 3
10 == 10
"hello" != "world"

Composite Types

List

Ordered collections of values.

[1, 2, 3, 4, 5]
["apple", "banana", "cherry"]
[true, false, true]
[[1, 2], [3, 4]]

Indexing:

Lists use 0-based indexing:

let numbers = [10, 20, 30]
numbers[0]
numbers[2]
numbers[-1]

List Operations:

Length([1, 2, 3])
Sum([1, 2, 3, 4, 5])
Avg([1, 2, 3, 4, 5])
Min([5, 2, 8, 1])
Max([5, 2, 8, 1])

List Transformations:

map([1, 2, 3], fn n => n * 2 end)
filter([1, 2, 3, 4, 5], fn n => n > 2 end)
reduce([1, 2, 3], 0, fn acc, n => acc + n end)

Heterogeneous Lists:

[1, "hello", true, 3.14]

Map

Key-value pairs (objects/dictionaries).

{ "name": "Alice", "age": 30 }
{ "x": 10, "y": 20 }
{ "nested": { "key": "value" } }

Field Access:

Use dot notation to access fields:

let user = { "name": "Alice", "age": 30 }
user.name
user.age

Nested Access:

let data = { "address": { "city": "Boston", "zip": "02101" } }
data.address.city
data.address.zip

Dynamic Construction:

def main() {
    let name = "Alice"
    let age = 30
    { "name": name, "age": age }
}
main()

Special Types

Null

Represents the absence of a value.

null

Use Cases:

  • Optional values
  • Uninitialized data
  • API responses with missing data

Checking for Null:

let value = null
value == null

Table

SQL query results from DuckDB.

SQL("SELECT * FROM 'data.csv'")

Table Properties:

  • Rows and columns
  • Can be queried with SQL
  • Can be converted to lists

Working with Tables:

SQL("SELECT * FROM 'users.csv'") as users
SQL("SELECT name, age FROM users WHERE age > 25")

Type Annotations

Variables carry runtime type information:

flow> 42 as x
✓ Bound 'x' to 42 : Int

flow> "hello" as greeting
✓ Bound 'greeting' to "hello" : String

flow> [1, 2, 3] as numbers
✓ Bound 'numbers' to [1, 2, 3] : List

Check Variable Types:

flow> :vars
✓ Variables:
  x = 42 : Int
  greeting = "hello" : String
  numbers = [1, 2, 3] : List

Type Coercion

Automatic Coercion

Some types are automatically converted:

5 + 3.14
10 * 2.5

No Implicit String Conversion

Warning

DSL does not automatically convert numbers to strings. Use explicit conversion functions.

"Age: " + 42

"Age: ${42}"

Custom Types

Define your own types using the class keyword:

class Person {
    name: String
    age: Int
    email: String
}

let alice = Person {
    name: "Alice",
    age: 30,
    email: "alice@example.com"
}

alice.name
alice.age

See Custom Types for more details.

Type Checking

Runtime Type Validation

Types are checked at runtime:

flow> "hello" + 42
✗ Error: Cannot add String and Int

flow> Upper(42)
✗ Error: Upper expects String, got Int

Type Safety

The DSL enforces type safety for operations:

"hello" + " world"
10 + 5
3.14 * 2

"hello" * 42
[1, 2] + 5

Common Type Patterns

Pattern 1: Working with Lists

let numbers = [1, 2, 3, 4, 5]

numbers |> map(_, fn n => n * 2 end)

numbers |> filter(_, fn n => n > 2 end)

numbers |> Sum(_)

Pattern 2: Working with Maps

let user = {
    "name": "Alice",
    "age": 30,
    "address": {
        "city": "Boston"
    }
}

user.name
user.address.city

Pattern 3: Type Conversion

let age = 42
"Age: ${age}"

Split("a,b,c", ",")

Join(["a", "b", "c"], ",")
